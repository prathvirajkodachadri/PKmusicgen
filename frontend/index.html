First-Run Setup

  1. Hardware detected automatically (see Settings).
  2. Choose a model below. Recommended: procedural-dsp (built-in, no download) for testing, stable-audio-open-1.0 for SFX/samples, ace-step-3.5b for music (Apache 2.0 commercial safe).
  3. Check license, VRAM requirement, size.
  4. Click Download (requires internet).
  5. After download, enable Offline Mode in Settings if desired.
