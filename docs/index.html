Features

Everything you need to round-trip MIDI ↔ Python with high fidelity.

  • 🎹

    Standard MIDI

    Supports .mid and .midi, Type 0 and Type 1, multiple tracks and channels, including drums on channel 10.

  • 🎼

    Full metadata

    Tempo changes, time signatures, key signatures, track names, lyrics, markers, instrument names and more.

  • 🎸

    All messages

    Program changes, control changes, pitch bend, aftertouch, polyphonic aftertouch — preserved exactly.

  • 🔍

    Two modes

    exact preserves raw MIDI data. readable adds musical helpers like chord detection and named notes.

  • 🛡️

    Safe by design

    MIDI is treated as untrusted. No eval / exec, sanitized filenames, validated output.

  • ✅

    Round-trip tested

    Verified that MIDI → Python → MIDI reproduces the original message stream.

Install

Python 3.10+ and a single dependency: Mido.

From source

git clone https://github.com/prathvirajkodachadri/PKmusicgen.git
cd PKmusicgen
pip install -r requirements.txt

Editable install

pip install -e .

Or just Mido

pip install mido

Why the web app needs no install

The in-browser converter above runs the real conversion pipeline via Pyodide. Your MIDI file is processed entirely in your browser — no upload, no server, no install.

The CLI tool above is the same code, just packaged for Python on your machine.

Usage

Convert a MIDI file and run the generated Python to recreate the original.

Basic

python midi_to_python.py input.mid
# Generates input.py

python input.py
# Generates input_recreated.mid

Choose output & mode

python midi_to_python.py song.mid -o song.py --mode readable
python song.py
# -> song_recreated.mid

All options

OptionDescription
-o, --outputOutput Python file (default: <input>.py)
--modeexact (default) or readable
--encodingOutput encoding (default: utf-8)
--no-commentsOmit comments
--stdoutWrite to stdout instead of file
--versionShow version
--helpShow help

Two conversion modes

Pick the trade-off that fits your use case.

Exact mode default

Preserves MIDI data as accurately as possible: ticks per beat, tracks, channels, note timing, durations, velocity, tempo, time/key signatures, instruments, control changes, pitch bend, aftertouch, and metadata.

"""
Generated by MIDI-to-Python.

Source MIDI: song.mid
Conversion mode: exact
"""

from mido import MidiFile, MidiTrack, Message, MetaMessage

TICKS_PER_BEAT = 480
MIDI_TYPE = 1
OUTPUT_MIDI = "song_recreated.mid"

mid = MidiFile(ticks_per_beat=TICKS_PER_BEAT, type=MIDI_TYPE)

track_0 = MidiTrack()
track_0.append(MetaMessage('track_name', name='Piano', time=0))
track_0.append(Message('program_change', channel=0, program=0, time=0))
track_0.append(Message('note_on', channel=0, note=60, velocity=64, time=0))
track_0.append(Message('note_off', channel=0, note=60, velocity=64, time=480))
mid.tracks.append(track_0)

mid.save(OUTPUT_MIDI)
